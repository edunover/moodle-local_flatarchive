## Deliberately retained

- Shared HTML templates/helpers still used by current exporters: age alone is not evidence of dead code.
- `db/upgrade.php`: removes the old `local_flatarchive_job` table during upgrades. Deleting this migration would leave old installation data behind.
- Read-only rendering of legacy values that can still occur in course settings.
- Git history, necessary source maps, and original user attachments.

The current runtime does not contain the PDF engine, mPDF/Composer bundle, old custom AJAX job endpoints or their processing table definitions. Removing repository files does not by itself prove that an old manually upgraded server has removed obsolete files: deploy a clean release directory through the Moodle installer and verify the installed tree.
